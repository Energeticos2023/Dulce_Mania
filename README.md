# DULCE MANÍA — Café & Postres

Sitio web para DULCE MANÍA, catálogo y pedidos por WhatsApp **943 518 901**.

- Catálogo interactivo de dulces, salados y bebidas.
- Acceso a [Yacusol App](https://energeticos2023.github.io/Yacusol-app/) y [YACUSOL](https://energeticos2023.github.io/YACUSOL/).
- Diseño adaptable a móviles.

## Publicar con GitHub Pages

En **Settings > Pages**, seleccionar **Deploy from a branch**, rama **main**, carpeta **/(root)** y guardar.

URL esperada: https://energeticos2023.github.io/Dulce_Mania/

**Importante:** confirmar precios antes de recibir pedidos; quedan pendientes las fotos originales del paquete de diseño anterior.
